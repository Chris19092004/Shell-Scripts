Por exemplo, a distribuição Arch Linux é tida como "difícil" para a maioria das pessoas por conta do processo de instalação,
tradicionalmente feito via linhas de comando para criar partições, definir nome do host, instalar pacotes essenciais, etc.
Escrevi um shell script para automatizar TODO esse processo. É de fato, algo mágico.

Nesse repositório pretendo subir shell scripts escritos por mim.
