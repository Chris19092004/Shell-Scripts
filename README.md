Shell Scripts são ferramentas poderosíssimas para automatizar tarefas que, executadas normalmente, linha por linha, seriam extremamente demoradas ou
repetitivas. Pense por exemplo que você quer separar centenas ou até milhares de fotos e vídeos em pastas, catalogadas por anos. Manualmente, isso
poderia levar horas, talvez até mesmo dias. Com um shell script, minutos.

Pense, por exemplo, na instalação e pós-instalação do sistema Arch Linux. Vários e vários comandos necessários para finalmente ter um sistema funcional, o
que deu ao OS a fama de "distro linux difícil". Com apenas dois shell scripts escritos por mim e encontrados nesse repositório, tudo (com exceção da definição
de senhas, por motivos de segurança) é automatizado. Desde configurações básicas do sistema como idioma e fuso horário, até mesmo a instalação de pacotes e
aplicativos e até mesmo a habilitação de servços como Docker, MariaDB, Flatpaks, etc. Pense no tempo economizado para ter um sistema perfeitamente funcional.

Nesse repositório pretendo compartilhar shell scripts que eu for escrevendo para automatizar os mais diversos processos.
